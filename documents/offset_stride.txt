ComputeOffset nasıl çalışıyor?

Kod:


for (size_t i = m_shape.size(); i-- > 0;)
{
offset += indices[i] * stride;
stride *= m_shape[i];
}


Örneğin:


shape = {2,3,4};
index = {1,2,3};


Başlangıç:


offset = 0;
stride = 1;

i = 2

offset += 3 * 1;


↓


offset = 3;


sonra:


stride *= 4;


↓


stride = 4;

i = 1

offset += 2 * 4;


↓


offset = 11;


sonra:


stride *= 3;


↓


stride = 12;

i = 0

offset += 1 * 12;


↓


offset = 23;


biter.

Aslında PyTorch'taki tensorların en önemli üyelerinden biri de budur:


shape
strides
data


Hatta reshape() çoğu zaman veriyi taşımadan sadece shape ve stride değerlerini değiştirerek çalışır. Bu yüzden stride kavramını anlamak tensor sistemlerinin temel taşıdır.


tensorlarda stride'ın gerçek tanımı:

İlgili eksendeki indeks 1 arttığında, fiziksel bellekte kaç eleman ilerlerim?

Mesela başlangıç tensoru:


[
[1,2,3],
[4,5,6]
]


Bellek:


[1,2,3,4,5,6]


Shape:


{2,3}
``


Stride:


{3,1}


Çünkü:


At({0,0}) = data[0]
At({1,0}) = data[3]


İlk boyutta 1 arttırınca:


0 → 3


gidiyoruz.

Yani:


stride[0] = 3


Transpose sonrası:


[
[1,4],
[2,5],
[3,6]
]


ama bellek hala:


[1,2,3,4,5,6]


Şimdi:


At({0,0}) = data[0]
At({1,0}) = data[1]


oluyor.

Yani ilk boyutta ilerleyince:


0 → 1


gidebiliyoruz.

Bu yüzden:


stride[0] = 1


Aslında şöyle düşün:


Shape = Tensorun görünüşü
Stride = Bellekte nasıl gezileceği
Data = Gerçek veri


Bu üçü birbirinden bağımsız şeyler.

Özellikle transpose sonrası bunu net görüyorsun:


Data değişmedi
Shape değişti
Stride değişti


Hatta bu yüzden aynı veriye:


data = [1,2,3,4,5,6]


iki farklı tensor bakabilir:


shape={2,3}
stride={3,1}


ve


shape={3,2}
stride={1,3}


İkisi de aynı veriyi görür ama farklı yorumlar.
